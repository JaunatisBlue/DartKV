## 上一步概述

六条 Qwen3-8B batch1 accuracy 任务已并行运行。由于单轮耗时较长，本阶段检查 lm-eval 是否
能使用逐 request SQLite cache 做中途续跑。

## 审计结果

lm-eval `CachingLM` 对 `generate_until` 且 `do_sample=True` 的请求明确禁用 cache 命中，原因是
复用响应会破坏不同 repeat 的随机采样语义。底层虽然调用 `cache_hook.add_partial`，wrapper
仍会把随机采样请求全部放入待生成列表。因此：

- 不能直接开启 `use_cache` 声称实现精确中途续跑；
- 从部分 response cache 恢复且重置 seed 会改变后续 torch RNG 状态；
- 当前继续以完整 repeat 为最小原子 checkpoint，优先保证论文采样正确性。

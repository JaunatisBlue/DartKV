## 上一步概述

- 已将 Kitty 的 Triton `qk_kernel`、`sv_kernel`、`kitty_attention_forward`、K/V 打包量化算子、`KittyCache`、`KVCache_Layer` 与 Qwen3 原生模型通过 `dart.kitty_kernels` 直接导出；没有用 DartKV 的同义实现替代 Kitty kernel。
- `examples/check_kitty_operator_parity.py` 已逐符号检查对象身份、源码路径、源码 SHA256 及 Kitty 的关键不变量（PAGE_SIZE=128、sink=32、INT2/INT4、25% boosted channels、prefill/decode 调用顺序），审计通过。
- 原生 Kitty Figure 5 已完成 batch32/64/128/256 与 batch512 OOM 边界，峰值显存与功耗记录在实验 JSON 中；加速比结果已纳入总审计。
- 为确保随机采样可恢复，`ExactSamplingCheckpointLM` 已支持固定 batch size 的批边界 checkpoint、请求顺序校验及 Python/NumPy/Torch/CUDA RNG 恢复；全套 55 个测试通过。
- 两个 Qwen3-8B GSM8K batch16 任务仍在 GPU0/GPU1 运行：FP16 repeat0 与 Kitty-Pro repeat1 的 request checkpoint 持续增长，当前显存约 46 GiB/卡、GPU 利用率约 90% 以上；功耗以 `power.draw`（瓦）记录，避免把 utilization 百分数误称为功耗。

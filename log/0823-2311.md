### 4. 找出并修复生成分叉的四个根因

在 Qwen3-8B、GSM8K 首个样本、paper sampling 协议下，旧 Dart 与 Kitty 都答对 18，
但响应措辞不同。沿 cache 张量逐层向下检查后确认并修复：

1. **量化算术 dtype**：Kitty 直接用 FP16 算 min/max、scale 和 round；Dart 原先提升到 FP32。
   一个构造页上，舍入边界造成 K 最大重建差约 2.16、V 最大重建差约 2.25。现在 K/V 都在
   源 dtype 中量化，并使用 Kitty 的 FP16/BF16 `1e-4` clamp；逐元素误差变成 0。
2. **PostQuant 返回时序**：Kitty 本次 attention 使用量化前快照，量化结果从下一次访问才生效。
   `DartHFCache` 现在采用相同生命周期，核心 cache 新增不物化完整结果的 `append()`。
3. **K/V 缓冲边界不同**：key 按 128-token Q-buffer flush，value 始终保留最新 128-token Local
   buffer，并逐 token 量化被驱逐的 value。新增 `value_local_tokens`，不再错误地强制 K/V 共用尾部边界。
4. **整页 prefill artifact**：若 prefill 恰好在 key 页边界结束，Kitty 模拟会在首次 decode 再量化
   最后一页；FP16 下该操作并非严格幂等。Dart 显式复现了这一可观察行为。

### 5. 验证结果

- 随机 FP16 页：Kitty fake quant 与 Dart packed/dequant 的 K/V 均为逐元素相等，max error 0；
- synthetic cache lifecycle：prefill 长度分别落在页中和页边界，后续连续 132 次 decode，
  每次返回的完整 K/V 都逐元素相等；
- Qwen3-8B、GSM8K 首样本、temperature 0.6/top-p 0.95/top-k 20、相同四类种子：
  Kitty reference 与 Dart 的完整生成文本逐字相等：
  `... At $2 per egg, she makes 9 * 2 = 18 dollars. The final answer is 18`；
- 双后端该样本 strict/flexible exact match 均为 1.0；
- 单元测试在本周期代码上全部通过（最终提交前再次执行）；
- `git diff --check` 通过。

有限样本仅用于语义验证，保存在被 Git 忽略的 `results/kitty_parity2/.../smoke_limit_1`，
没有被当作论文 Table 3 结果。

## 当前判断

算法准确率路径已从“近似搬运”提升为可测试的逐元素、逐 decode 和真实 8B 文本一致。
这使后续 Table 3 可以优先用 Kitty reference 复核论文，再用 Dart 结果确认搬运没有引入数值偏差。

但论文复现目标尚未完成：Table 3/4 完整数据尚未跑完，Figure 4 promotion sweep 尚未执行，
Figure 5 必须使用 Kitty 自定义 Qwen3 模型及 Triton packed attention；当前 DartHFCache 是
materialization correctness path，不能用其延迟冒充论文吞吐。
